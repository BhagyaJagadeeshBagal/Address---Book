### 🚀 Key Mechanics

* 🛠️ *Full CRUD Engine* — Seamlessly create, read, update, and delete entries.
* 💾 *Persistent Storage* — Saves and populates database states directly via flat text files.
* 🧩 *Modular Blueprint* — Structured with isolated modules for logic flow, population, and file I/O operations.

---

### 💻 Production Controls

#### 1. Compile Circuit
Feed the modules into your GCC compiler to generate the binary core:
bash
gcc main.c contact.c populate.c file.c -o addressbook


#### 2. Execute Module
Run the compiled machine layer directly from your local terminal environment:
bash
./addressbook
